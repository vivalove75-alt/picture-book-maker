📚 나만의 그림책 만들기

생각을 적고, 주인공을 만들고, 한 장면씩 그림책을 완성해요!

1. 이야기
2. 캐릭터
3. 페이지 그림
4. 완성

🌱 1단계. 어떤 이야기를 만들까요?

그림책의 주제를 정해요. 짧게 적어도 괜찮아요!

💡 주제가 떠오르지 않으면 “우정”, “모험”, “동물”, “환경”, “학교생활”처럼 좋아하는 낱말부터 시작해 보세요.
입력한 내용은 자동 저장돼요.

🧑‍🎨 2단계. 이야기 속 친구를 만들어요

주인공의 모습을 상상해 적어 주세요. 떠오르는 것만 적어도 돼요.

⭐ 페이지마다 같은 주인공이 나오도록 이름과 생김새를 똑같이 사용해요.
자동 저장 중

🖼️ 3단계. 페이지마다 장면을 만들어요

각 페이지의 이야기와 그림 장면을 적어 주세요. 한 장면씩 카드를 채우면 돼요.

✏️ ‘이야기’에는 어떤 일이 일어나는지, ‘그림 장면’에는 그림에 무엇이 보이면 좋을지 적어요.
입력할 때마다 자동 저장돼요.

🎉 4단계. 나의 그림책을 확인해요

내용을 확인하고, 페이지 그림을 만들 때 사용할 문장을 복사해 보세요.

이 웹앱은 내용을 저장하고 그림 만들기 문장을 준비해요. 실제 그림은 ChatGPT 등의 이미지 생성 기능에 문장을 붙여넣어 만들 수 있어요.

💾 내용은 이 기기의 브라우저에 자동 저장돼요. 다른 기기에서도 사용하려면 ‘내 그림책 파일 저장하기’를 눌러 파일을 보관하세요.

나의 생각과 상상력으로 만드는 세상에 하나뿐인 그림책
